# Wiremix presentation

## Language

**Control card**:
The displayed identity and controls for one audio stream, device endpoint or configuration device.

**Object-list viewport**:
The visible portion of an audio section's list of control cards. A partially visible card still participates in live updates; selection scrolling uses complete cards.

**Section**:
One of the five simultaneously displayed audio lists: Playback, Recording, Output Devices, Input Devices or Configuration. The focused section receives keyboard commands and supplies contextual shortcut hints.
_Avoid_: Tab, except in historical configuration and shortcut names.

**Dashboard**:
The one-page presentation of all five audio sections and their contextual shortcut strip.
